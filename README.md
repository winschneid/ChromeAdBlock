# Simple Ad Blocker (ホワイトリスト対応)

Chrome 拡張機能 (Manifest V3)。広告配信ドメインへの通信をブロックし、
ホワイトリストに登録したサイトでは広告を許可します。

## インストール(開発者モード)

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `ad-blocker` フォルダを選択する

## 使い方

- **ツールバーのアイコン**: 今見ているサイトのブロックをON/OFF。OFFにすると
  そのドメインが自動でホワイトリストに入り、タブが再読み込みされます。
  ホワイトリスト中のサイトではアイコンに `OFF` バッジが出ます。
- **詳細設定**: ホワイトリストの一覧・追加・削除、トラッキングブロックの
  ON/OFF、CSSによる残骸非表示のON/OFF。

ホワイトリストはサブドメインも含めて一致します
(`example.com` を登録すると `news.example.com` も許可)。

## 仕組み

| ファイル | 役割 |
| --- | --- |
| `rules/ads.json` | 広告配信ドメインのブロックルール(静的, priority 1) |
| `rules/tracking.json` | 解析/トラッキングのブロックルール(既定は無効) |
| `background.js` | ホワイトリストを `allowAllRequests` の動的ルール(priority 1000)に変換 |
| `hide.css` | ブロック後に残る空の広告枠を非表示にする |
| `content.js` | ホワイトリスト時に `<html>` へ `.abw-allow` を付けて `hide.css` を無効化 |

ブロックは declarativeNetRequest で行うため、リクエスト自体がネットワークに
出る前に止まります。ホワイトリストのルールは優先度が高いので、同じ広告ドメインでも
そのサイト配下では許可されます。

## カスタマイズ

- ブロックしたいドメインを増やす → `rules/ads.json` の `requestDomains` に追記
- 誤検知でレイアウトが崩れる → `hide.css` の該当セレクタ行を削除
- 変更後は `chrome://extensions` で拡張機能の再読み込みが必要です

## 開発用テスト

```
node test.js
```

ホワイトリスト判定と生成されるルールを Node 上で検証します
(配布時は `test.js` を削除して構いません)。

## 制限

- ルールは同梱の固定リストのみで、EasyList のような大規模フィルタの
  購読機能はありません。
- YouTube のような、広告を本体と同じドメインから配信するサイトは
  この方式では止められません。
